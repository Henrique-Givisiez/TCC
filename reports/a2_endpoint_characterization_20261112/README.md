# Caracterização visual A2

Quatro painéis completos, quatro versões compactas, uma comparação das quatro execuções e cinco figuras complementares. Veja [relatorio.md](relatorio.md) e [manifest.json](manifest.json).

Reprodução, na raiz do repositório:

```bash
python3 reports/a2_endpoint_characterization_20261112/scripts/generate.py
python3 reports/a2_endpoint_characterization_20261112/scripts/write_report.py
python3 reports/a2_endpoint_characterization_20261112/scripts/validate.py
```

Dependências: Python 3, numpy, pandas, matplotlib e Pillow (validação visual automática). Entradas: somente A2 de 06/11/2026.
